# Postponed Todos

A Flutter app for tasks that feel too small, vague, or emotionally heavy to schedule right now.

## What it is
Postponed Todos is built for the gray zone between a calendar and a note.

It helps you keep track of things you do want to return to — without forcing an exact date too early and without letting them disappear into a pile of forgotten notes.

Examples:
- call parents
- book a hospital appointment
- request a refund
- hang the curtains
- organize one corner of the house

## Core idea
- low-pressure capture
- gentle rediscovery
- postponed is a valid state, not a failure state
- suggestion-driven return flows instead of deadline-driven guilt

## Current status
This repository contains the Flutter client code for the app prototype and ongoing product exploration.
