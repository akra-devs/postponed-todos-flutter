# postponed_todos

Flutter app source prepared for public repository publishing.

## Included
- `lib/`
- `test/`
- `android/`, `ios/`, `linux/`, `macos/`, `web/`, `windows/`
- `pubspec.yaml`, `pubspec.lock`
- `analysis_options.yaml`
- `.metadata`

## Excluded from this public export
Internal workspace files, local machine state, generated build artifacts, VCS metadata, and secret-like files were intentionally removed.

## Getting started
```bash
flutter pub get
flutter run
```
